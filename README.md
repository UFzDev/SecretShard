# ⚡️ Bun + Vite Premium Template

Plantilla base ultraligera para el inicio rápido de proyectos modernos con un entorno preconfigurado de alto rendimiento.

---

## 🚀 Inicio Rápido

Para desplegar tu entorno de desarrollo, ejecuta:

### 1. Clonar el repositorio
```bash
git clone https://github.com/UFzDev/template-bun.git mi-proyecto
cd mi-proyecto
```

### 2. Instalar dependencias
```bash
bun install
```

### 3. Lanzar entorno de desarrollo
```bash
bun run dev
```

### 4. Construir para producción
```bash
bun run build
```

---

## 🏗️ Estructura del Proyecto

- `public/`: Archivos estáticos e iconos.
- `src/main.ts`: Punto de entrada lógico.
- `src/style.css`: Estilos base y sistema de diseño.
- `index.html`: Punto de entrada HTML.
- `tsconfig.json`: Configuración de TypeScript 5.x.

---

## 🛠️ Stack Tecnológico
- **Bun** (Runtime & Package Manager)
- **Vite 5** (Build Tool)
- **TypeScript 5.x** (Language)
